- **Integrations** — VoIP (Zadarma), messaging, CRM, payments/installments.
- **AI products** — offline voice assistants / kiosks (Vosk STT, Piper TTS, deterministic NLP).
- **Growth** — landing pages, Meta Ads, marketing automation.
